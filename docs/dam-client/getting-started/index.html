Getting started

Sambafied DAM Client is for Windows only. Have your evaluation build, your administrator's Author address and sign-in instructions, and an empty folder for this connection.

1. Install and open Sambafied​

If you have an evaluation build, follow the installer instructions supplied with it. For a tester ZIP, use the tester installation guide. Open Sambafied AEM from Start after installation. If the app shows requirements to resolve, review them before continuing.

Illustrative sample. Review the prerequisites reported by Sambafied after launch.

2. Add a Sambafied licence​

If your build asks for a licence, open About → Manage licence, enter the key you received and select Activate. Wait for the status to show that the device is activated. Then select Close. Activation and signing in to AEM are separate steps. Licence help

Illustrative sample. Select Activate after entering your own key.

Illustrative sample. Check the activation status and offline expiry before signing in to AEM.

3. Add your AEM connection​

Open Connections, then select Add. Enter the Author address from your administrator and give the connection a name you will recognise. Use the DAM folder your administrator assigned you.

Illustrative sample. Select Add on the Connections page.

Illustrative sample. Enter the Author and connection details, then select Add Instance.

4. Sign in to AEM​

For local or on-premises AEM, choose the sign-in method your administrator provided and select Sign in. For AEM Cloud Service, use the Cloud Author address and complete the Adobe sign-in presented by your organisation. Choose Remember sign-in on this PC only if you want this device to retain that connection's session.

Illustrative sample. For a local Author, check the address and choose whether to remember sign-in.

Illustrative sample. For Cloud AEM, check the Cloud Author address and deployment type.

5. Choose a work folder​

Use the work folder chooser to select a new empty Windows folder for this connection. Use a different folder for every connection. Once setup finishes, check that Home shows the intended connection before opening files.

Illustrative sample. Select a separate empty work folder for this connection.

Illustrative sample. Connected Home offers Browse files and Open folder.

6. Browse and open your first asset​

From Home select Browse files. Choose a small test asset you are permitted to use. Open its actions menu and select Open, or inspect Preview and choose Download original if you need the full file. Wait for the transfer if the file is cloud-only.

Illustrative sample. Choose a test asset in My assets.

Illustrative sample. Open the selected asset from its actions menu.

7. Check the result​

Confirm the intended asset opens in your usual Windows application. If it stays pending or reports an error, open Transfers and inspect the item before retrying. When you are ready to edit, follow open and edit and check transfer status after saving.

Illustrative sample. Transfer details show the queued item and its progress.

For other tasks, open the Desktop user guide. If setup stops, see troubleshooting.
