Welcome to Sambafied AEM Desktop

Guide home · Coverage and gaps · Image plan

Development guide draft, reviewed 28 October 2026. Steps describe the approved contract and are conditional on the installed build advertising that capability. Product and target acceptance remain separate.

Sambafied connects an AEM Assets repository with a Windows desktop work folder. It is intended for finding originals, working in local applications and publishing reviewed changes. The desktop shell, Agent and Explorer integration have separate responsibilities. A screen appearing in the offline showcase is not a working connection to AEM.

This is a development user-guide draft, not a general-release support promise. Use it alongside the feature status, workflow contracts and acceptance contract. A disabled or absent capability must remain unavailable; these instructions do not authorize bypassing it. The product still has outstanding build/runtime, installed, server and creative-application qualification.

Choose the right guide​

New users should read installation, connections, browsing and local editing in that order. Existing users should review local-state meanings and differences before publishing work. Administrators should read compatibility, Settings, Explorer and recovery. Evaluators should use the offline showcase guide, whose sample actions remain in memory.

What is different​

Sambafied adds named independent connections, editable Explorer names, a native CFAPI work folder, durable operation/recovery records, optional reviewed publication policy and explicit safe storage tools. It does not inherit Adobe's SSO entitlement, installers, macOS support, protocol handler, cache layout or published system requirements. Differences explains the intended boundaries.

Current development updates​

The shared view now has compact Assets commands, flowing Edited locally records, a wider Connections filter, two Home targets in the brand, organized Settings, Copyright Sambafied notices and a content-sized menu. Recent integration adds Collections and places production-only defaults under Advanced/search. The showcase close/hide/show cycle is wired; its tray remains a panel. These are presentation milestones, not an application release. See release record.
