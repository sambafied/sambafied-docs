Local availability, pins and reconnecting

Guide home · Find a task

Development preview. This guide describes work in progress, not a supported customer release. Follow a procedure only when its controls are available in your build. Availability depends on the server and your permissions.

Download originals and linked files while online before disconnecting. A thumbnail or filename does not guarantee offline access.

StateWhat it means
Cloud-onlyDownload the original while online.
Available locallyThe original is on this PC; cleanup may reclaim eligible clean copies.
Pinned or pendingRetention was requested; check download completion.
Edited locallySaved changes may still need uploading.
Queued or uploadingInspect progress for the selected saved copy.
Uploaded or processingTransfer and server processing may finish separately.
ConflictCompare local and server versions before replacement.
Unknown or detachedCheck the connection, account and result before acting.

Optional automatic uploads​

If offered, automatic upload requires explicit opt-in for the connection. Check its policy and paused work before relying on it. Saving or pinning alone is not confirmation that a file uploaded.

Work offline and inspect local state​

Download the originals and linked files you need while online.

  1. Inspect local availability for each required asset.
  2. While offline, open only files whose originals are available on this PC.
  3. Save normally.
  4. Reconnect to the original connection and account before reviewing uploads.

A visible cloud-only file is unavailable offline. Local edits remain separate from uploaded changes.

If the account or server copy is uncertain, preserve local work and resolve the connection before refreshing or uploading.

Keep originals offline with pins​

Have enough disk space for the selected files and related assets.

  1. Select assets or a folder and choose Pin or Keep originals offline, when available.
  2. Review files, estimated space and related-file options.
  3. Wait for downloads and inspect partial or denied items.
  4. Unpin when you no longer need local retention.

Pinning requests retention; only completed downloads are available offline. Unpinning does not delete the server asset or local edits.

If space is insufficient, reduce the selection. Do not clear unuploaded edits to make room.
