Terms and deliberate differences

Guide home · Coverage

TermMeaning in Sambafied
ConnectionNamed server/root/auth context with an independent original principal.
OriginalVerified full asset bytes, distinct from a thumbnail or placeholder.
GenerationA particular captured set of local bytes; a later save is another generation.
Desired/effective settingSaved intent versus a reviewed Agent/Windows effect that actually applied.
Operation receiptDurable original-request outcome, not a transient success message.
Unknown outcomeThe remote result needs reconciliation; not permission to resend blindly.
AliasCollection view reference to one canonical asset, not another edit history.
PinRetention intent; completion must be observed independently.
Free up spaceQualified local resident-data release, not deletion from AEM.
DiscardReviewed local replacement protected by recovery bytes.

Adobe documentation inconsistencies​

The current guide contains conflicting descriptions of refresh and operation availability during transfers. Its overview/release material also needs interpretation beside later task descriptions. Sambafied follows its own explicit workflow contracts instead of selecting whichever Adobe sentence is easiest to implement. The review records these ambiguities and distinguishes current online documentation from the earlier3.0.2 screenshot/source audit.
