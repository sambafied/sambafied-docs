Screenshot and illustration plan

Guide home · Coverage

All 52 image slots below use explicit text placeholders. There are no application screenshots or generated UI images in this delivery. The blocks make no product-evidence claim. Do not replace them with Adobe artwork or a generated “working app” image. Existing candidate screenshots under docs/research/evidence may guide composition, but cannot qualify current installed behavior.

For each replacement: record source revision, EXE SHA256, OS/build, scale, viewport, server type, sample/live status, scenario, expected/actual result, time and reviewer. Redact secrets and personal/asset data. Capture default600 × 860 and minimum400 × 480 logical sizes where relevant, plus loading/empty/error/denied/cancel/restart and keyboard focus as applicable. Mark a mock capture SAMPLE prominently; it can illustrate a layout, never prove server/Explorer/packaging behavior. Preserve old receipts as historical rather than overwriting their identity.
