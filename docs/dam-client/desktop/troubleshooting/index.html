Troubleshoot without losing work

Guide home · Coverage and gaps · Image plan

Development guide draft, reviewed 28 October 2026. Steps describe the approved contract and are conditional on the installed build advertising that capability. Product and target acceptance remain separate.

Connection, login or SSO fails​

Check the intended Author origin, deployment, network reachability, principal and operation category. Separate an expired session from a denied resource or unsupported adapter. Browser login success alone does not prove desktop DAM API eligibility. For SAML redirects or SaaS failures, retain a redacted sequence and ask the authentication owner to check the qualified profile. Do not copy Adobe's debug environment variables or raw request logging instructions into Sambafied.

TLS or proxy failures​

Record a redacted certificate/proxy error and the configured host. Ask the administrator to correct its supported certificate chain or approved proxy route. Do not disable TLS checking, change trust or save proxy credentials as an ad hoc fix. A browser that accepts a site does not establish the client transport is correctly configured.

Asset is missing, expired or denied​

Check connection, root, query and page completeness. Refresh the observation. A missing item can be filtered, expired or permission-denied; it is not proof of deletion. Expired-asset authorization is enforced by the server and must not be bypassed by a cached copy or administrator role assumption. Refer AEM policy configuration to the server administrator.

Download, upload or server processing fails​

Inspect Transfers/Operations for the original item, generation and phase. Check disk space and network; distinguish initiation/bytes/commit/processing. Reconcile unknown outcomes before retrying. Server connector compatibility belongs to the AEM administrator and the qualified target matrix; do not publish Adobe's connector version as a Sambafied requirement.

Linked assets are absent​

Check dependency permissions, original downloads, application format/version and stable paths. Preserve the document. Use the creative application's supported relink tools only under an explicit plan; do not rewrite binary files from guessed metadata.

Saved changes do not appear in AEM​

Check Edited locally, selected immutable generation and publication policy. Local Save is not Upload Changes. Confirm binary completion, server processing and separately dependent check-in. A later save may still be dirty after an earlier generation commits.

Window appears unresponsive or blank​

Record the exact EXE/build, renderer, last action and visible error before restarting. Keep local work and inspect original operations on return. Use supported Show/Keep window open/close-review actions. Do not kill an unrelated Agent, delete a cache or reinstall as an automatic first step. A historical blank software/GPU capture is not proof the current installed client is broken.

Support destination and logs​

PARTIAL: approved support contact, final user-facing log discovery and redacted-bundle controls still need a release-qualified recipe. Until then use the responsible project/support owner with a manually redacted report. Never upload private logs, cookies, headers, signed URLs or asset contents just because Adobe's documentation suggests sharing its Logs folder.
