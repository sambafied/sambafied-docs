Find, preview and select assets

Guide home · Coverage and gaps · Image plan

Development guide draft, reviewed 28 October 2026. Steps describe the approved contract and are conditional on the installed build advertising that capability. Product and target acceptance remain separate.

The primary browsing area keeps the current location, navigation, query, sorting and presentation controls together. Asset-specific or infrequent commands live in grouped actions. Collections, Transfers, Edited locally and Inbox are distinct destinations, not additional toolbars stacked above the list.

Home describes the selected connection; My assets opens its DAM view. A contextual Search may filter the current screen, while repository asset search must advertise its remote scope. Do not use a local filtered result as a complete repository inventory. Long menus and filters must show usable labels; short windows may scroll rather than hide commands.

Keyboard and accessible use​

Use Tab to reach named controls and inspect visible focus. The brand title supports Enter/Space through the Home route. Every pointer action has a keyboard/accessibility requirement in the contracts, but the full installed Narrator/high-DPI/focus-return matrix remains unverified. Repeated sample-row focus replacement and scrolled popup UI Automation targeting have known limitations; avoid documenting an untested arrow-key or screen-reader sequence as accepted.

W04​

Browse folders and change views​

Documentation: FULL. Before you start: Connect to a readable DAM root.

Procedure. Open My assets. Follow the folder tree or path navigation. Choose a supported list/grid/card presentation. Use Back to revisit the prior location and Refresh to obtain another observation. Read the loaded-page/completeness message before interpreting an empty view.

Expected result. The displayed location and active connection identify the remote scope. Refresh does not expand a previously approved action plan.

Cancel, errors and recovery. An empty folder, incomplete page, denied folder and failed refresh are different results. Keep the last known view while resolving an error; do not infer deletion from a missing row.

W05​

Search and sort​

Documentation: PARTIAL. Before you start: Use a connected root and an adapter that advertises the required search capability.

Procedure. Open Search in My assets and enter a name/title or supported metadata query. Read the scope and loaded-results count. Choose a supported sort field and direction. Use relevance only for a supported search result. Clear the query to return to browsing.

Expected result. Results stay inside the configured root with stable asset identities. Metadata and wildcard behavior depend on the qualified query adapter, not Adobe examples.

Cancel, errors and recovery. When a search fails or returns only a page, retain the query and show the limit. Do not treat a local screen filter as a complete repository search. Exact wildcard/metadata recipes await target qualification.

Remaining documentation gate. Publish exact supported query grammar, metadata fields and wildcard examples per target after acceptance.

W06​

Select and act on multiple assets​

Documentation: FULL. Before you start: Know which rows are loaded and which action is eligible for each item.

Procedure. Select one or more assets using their selection controls. Check the selected count and common actions. Select All applies to the loaded set. For an action on all results, open the separately labelled review, inspect its complete count and approve that exact plan.

Expected result. A mixed selection exposes only suitable actions. A later refresh cannot add unreviewed members to the accepted batch.

Cancel, errors and recovery. Clear the selection or cancel its review to back out. A disabled action may reflect mixed states or unsupported capabilities; reduce the selection and inspect individual status.

W07​

Preview an asset​

Documentation: FULL. Before you start: Select a readable asset.

Procedure. Open the asset detail/preview surface. Inspect title, type, size, remote identity and available metadata. Distinguish a thumbnail from a verified original. Use the original-download action when full bytes are needed.

Expected result. Preview failure is not evidence that the original is missing. Download status reports the actual original transfer.

Cancel, errors and recovery. For a missing thumbnail, use metadata and retry the preview. Permission or original-read errors remain visible. Native media/format support must be qualified before promising playback.
