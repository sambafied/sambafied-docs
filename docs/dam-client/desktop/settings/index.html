Preferences: General, Storage and Advanced

Guide home · Coverage and gaps · Image plan

Development guide draft, reviewed 28 October 2026. Steps describe the approved contract and are conditional on the installed build advertising that capability. Product and target acceptance remain separate.

General​

Review startup and whether the window opens at launch. A tray-only preference must still leave an accessible way back to the window. Window dimensions can be reset to the approved600 × 860 logical-pixel default. Work-folder publication policy belongs to the original connection and cannot redirect accepted jobs.

Storage​

Inspect usage, quota and eligible auto-clean choices. Usage must distinguish known and unknown measurements. Setting a quota does not clear protected work. See storage operations.

Advanced​

Maintenance tools are collapsed until needed. An active review must remain reachable even when a screen search is active. Production-only connection defaults include temporary directory, related/pin policy, Reveal destination, naming, per-file/part/global transfer limits, secure network settings, drive intent and original-session reset/repair. These are placed under Advanced and participate in search.

Saving desired settings is distinct from applying reviewed Agent settings, cleaner/quota or Windows startup effects. Inspect the saved and effective results, and reconnect where required. No particular concurrency default is inherited from Adobe's slider. Proxy eligibility and trusted certificate changes require their own approved connection setup; TLS verification remains enabled. A saved drive choice is intent, not an existing mapping.

Scoped session maintenance​

Sign-in reset and browser ownership-record repair are different reviewed operations for the original connection. Read their consent and outcome. They must not erase all browser profiles, another user's cookies or unrelated saved identities. This document never instructs a user to edit private configuration or disable certificate validation.

W35​

Change preferences deliberately​

Documentation: PARTIAL. Before you start: Review which connection and app-wide preferences you intend to change.

Procedure. Open Settings/Preferences. General contains startup/window/work-folder choices; Storage contains usage/quota/cleanup policy; Advanced contains maintenance and connection defaults. Review the relevant values. Save desired settings, then separately review/apply Agent or Windows effects where offered. Use Reload saved settings or Cancel draft to abandon uncommitted edits.

Expected result. Saving desired settings does not create a drive mapping or prove startup registration. Running reviews and their consent remain separate from navigation.

Cancel, errors and recovery. For network/auth/mount-affecting changes, follow the quiesce/reconnect result. Cancel must leave prior settings. Do not use TLS-off switches or broad browser-cookie deletion. Exact installed application order is still being qualified.

Remaining documentation gate. Final installed atomic-save/effect-application, startup and restart procedures need acceptance.
