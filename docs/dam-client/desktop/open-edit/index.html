Open, reveal, edit and check out

Guide home · Find a task

Development preview. This guide describes work in progress, not a supported customer release. Follow a procedure only when its controls are available in your build. Availability depends on the server and your permissions.

Choose Open for viewing, Edit for making changes and Reveal to locate the file. Saving in a desktop application keeps work on this PC until you upload it. Checkout and check-in are separate server actions where supported.

Related-file downloads and drag-and-drop vary by build and application. Use the available Open or Upload File action when a drag gesture is unsupported.

Open and Open With​

Have a Windows application associated with the file type.

  1. Select the asset and choose Open.
  2. Use Open With to choose another application if offered.
  3. Wait for any original download before opening the file.

Open uses the local original and does not automatically check the asset out.

If no application opens, check the Windows file association and download status. Use Edit when you intend to change the asset.

Edit, save locally and publish deliberately​

Have edit permission and check whether your server supports checkout.

  1. Select the asset and choose Edit.
  2. Review any checkout message and download the original if needed.
  3. Make changes in your desktop application and save locally.
  4. Return to Edited locally, review the saved copy and choose Upload Changes when ready.

Saving on this PC does not by itself upload changes. Check-in is separate where supported.

If another person changed the server copy or owns checkout, preserve your local file and compare the versions before resolving the conflict.

Reveal the right folder​

Select the asset or folder you want to locate.

  1. Choose Reveal or Show work folder.
  2. Check whether the destination is the work folder, selected asset, cache or an exported copy.
  3. Use the managed work-folder copy for editing and uploading changes.

An exported copy is independent of the managed asset.

If the destination is unavailable, inspect connection and download status. Do not move or delete cache files to repair it.

Drag assets in or out​

Drag-and-drop is still being checked across Windows and desktop applications. Use Open or Upload File when unavailable.

  1. For drag-out, download the original and select the asset.
  2. Drag to a supported destination and check whether it creates a copy or link.
  3. For drag-in, drop local files on the upload destination offered by the app.
  4. Review the target folder, filenames and collision choices before confirming.

A drag gesture must not bypass the upload review.

Cancel the review to stop an import. If a gesture fails, use the file picker rather than moving files into cache folders.

Check out or check in separately​

Checkout and check-in depend on server support and permission.

  1. Inspect the asset checkout owner and status.
  2. Choose Check out to reserve it, if available.
  3. Upload saved changes separately when ready.
  4. Choose Check in and inspect the result.

Treat checkout as advisory in this preview. A badge does not guarantee exclusive editing or replace conflict checking.

If another person owns checkout or ownership changes, keep local work and ask your administrator. Upload does not necessarily check in.
