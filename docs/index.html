How to read these docs​

Observed locally means a bounded scenario has been exercised against a local development AEM Author. Implemented primitives means the relevant code or command exists, without implying the whole workflow has passed acceptance. Planned or pending qualification means it should not be relied on as a released capability.

The current source review was made on 20 October 2026. Product behavior is evolving; older individual preview notes may describe narrower slices.
